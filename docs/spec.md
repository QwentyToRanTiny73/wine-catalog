РЕШЕНИЯ (запиши в docs/decisions.md)

* Р1. Данные сайта остаются публичными.
* Р2. Админка нужна, но без пароля в коде.
   * Вход — fine-grained токен GitHub с правом Contents read/write только на этот репозиторий; хранится в sessionStorage.
   * Админ правит образцы и дескрипторы ароматов на /admin/. Сохранение — коммит JSON через GitHub API, затем пересборка.
   * Старый вход по паролю удалить полностью.
* Р3. Исходный Excel хранится в data/source/ и в .gitignore; в репозиторий попадает только сгенерированный JSON.
* Р4. Сборка: Vite и обычный JavaScript (ES-модули), без фреймворка. Деплой только папки dist/ и только из main.
* Р5. Ветку main создать из текущей ветки по умолчанию. Переключение ветки по умолчанию, видимость репозитория и настройки Pages делаю я.
* Р6. Страницы: главная (о базе, цифры), /baza/ (единственная таблица), /aromaty/ (колесо), /arkhiv/, /admin/.
* Р7. Канонические названия сортов утверждаю я. Скрипт готовит таблицу data/variety-map.csv, спорные случаи не решает сам.
* Р8. Стиль «научная ясность»: светлый фон, один винный акцент, гротеск с кириллицей (например Onest или Golos Text), моноширинные цифры (например JetBrains Mono или IBM Plex Mono). Шрифты подключаются локально через @fontsource. Fraunces и Instrument Serif не использовать: в них нет кириллицы.
* Р9. Иконки — собственные SVG: тонкая линия, монохромные, строгие, в духе научного журнала «Магарач. Виноградарство и виноделие», не мультяшные. Логотипы института и журнала не перерисовывать.
* Р10. Дескрипторы ароматов можно брать из открытых источников. У каждой записи URL, дата обращения и пометка «интернет, проверить». Нет источника — нет записи. * scripts/build_data.py (Python, openpyxl): Excel из data/source/ → src/data/samples.json и data/report.md.
* Нормализация по утверждённой variety-map.csv; купаж — массив varieties.
* Неизвестный сорт останавливает скрипт с понятной ошибкой.

Архитектура:

* Общие шапка и подвал — один модуль.
* Состояние фильтров и сортировки — в адресе страницы.
* Фильтр по сорту учитывает купажи.
* Пустые значения при сортировке всегда в конце.
* На ширине до 640 px таблица превращается в карточки.
* Все библиотеки — из npm с точной версией. Вывод данных — через textContent или экранирование.

Доступность:

* axe-core: 0 нарушений critical и serious на всех страницах.
* label у полей; сортировка с клавиатуры, aria-sort.
* Карточка образца — <dialog>: фокус, Esc, возврат фокуса.
* Контраст не ниже 4.5:1; prefers-reduced-motion.
* Сделай scripts/audit.mjs (Playwright + axe-core) и команду npm run audit.

Колесо ароматов:

* Своя таксономия на русском, три уровня: категория → группа → дескриптор. Колесо Noble (UC Davis) не копировать.
* Файлы: src/data/aroma/taxonomy.json и varieties.json; у каждой записи intensity 1–3 и source.
* Поведение:
   * выбор одного или 2–3 сортов для сравнения;
   * подсказка при наведении и фокусе;
   * щелчок по дескриптору — список сортов и ссылка на /baza/ с фильтром;
   * из карточки образца — «Профиль аромата сорта»;
   * сорт без данных — «Описание аромата для сорта ещё не внесено»;
   * текстовая альтернатива колесу.
* SVG, управление с клавиатуры, работает на 390 px. Дополнительный вес не больше 50 КБ gzip.

SEO: title и meta description на каждой странице, Open Graph, sitemap.xml, robots.txt.
Вес: /baza/ не больше 233 КБ — половина от текущих 467.
