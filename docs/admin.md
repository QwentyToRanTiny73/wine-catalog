# Админка: как войти и что она делает

Адрес: https://qwentytorantiny73.github.io/wine-catalog/admin/ (в меню её нет, поисковикам закрыта).

## Что можно править (Р27)

- **Дескрипторы ароматов** (`data/aroma-descriptors.csv`): интенсивность 1–3, статус
  («интернет, проверить» → «проверено» или «скрыто»), новые записи. Новая запись принимается только
  с дословной цитатой и ссылкой на источник (Р10); дата обращения ставится сегодняшняя.
- **Пометки к образцам** (`data/sample-notes.csv`): добавить или удалить. Номер образца и поле проверяются
  по данным сайта; у образцов «б/н» пометок быть не может.
- **Значения анализов здесь не правятся** — только в исходном Excel и через `scripts/build_data.py`.

## Как сохраняется

«Сохранить на сайт» делает коммит этого CSV в `main` от вашего имени. GitHub Actions пересобирает сайт
(перед сборкой: `build_aroma.py` и `build_notes.py`), через 1–2 минуты правка видна на сайте.

- Если файл успели изменить в другом месте — сохранение не пройдёт («файл изменился»), ничего не затрётся.
  Нажмите «Выйти», войдите снова и повторите правку.
- Админка пишет прямо в `main` (Р27). Если включить на GitHub защиту ветки `main` («только через pull request»),
  сохранение перестанет работать — на странице будет ответ GitHub с причиной.
- Если сборка найдёт ошибку в CSV — сайт останется прежним, а в разделе Actions на GitHub будет красная
  отметка с текстом ошибки.

## Токен GitHub (один раз)

1. GitHub → аватар → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** →
   **Generate new token**.
2. **Token name**: `wine-catalog admin`. **Expiration**: 90 дней (когда истечёт — создать новый так же).
3. **Repository access**: **Only select repositories** → `QwentyToRanTiny73/wine-catalog`.
4. **Permissions** → **Repository permissions** → **Contents**: **Read and write**. Больше ничего не включать
   (Metadata: Read-only GitHub добавит сам).
5. **Generate token**, скопировать (GitHub покажет его один раз), вставить на странице `/admin/` в поле «Токен GitHub».

Токен хранится только в этой вкладке браузера (sessionStorage) и стирается при её закрытии или по «Выйти».
Отправляется только на `api.github.com`. Не пересылайте токен и не сохраняйте его в файлах репозитория.
Если токен мог утечь — удалите его там же, в Fine-grained tokens (**Delete**).
